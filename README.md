# 💳 FinPay — Financial & Customer Analytics

An end-to-end FinTech analytics project featuring data cleaning in **Python**, local **MySQL** storage, and an interactive **Power BI** executive dashboard.

---

## 📌 Executive Summary
Analyzed **50,000+ transaction records** and **5,000 customer profiles** to extract operational, financial, and risk insights[cite: 2, 3].

- **Total Processed Volume:** ₹ 1.33M (filtered dashboard view)
- **Key Customer Drivers:** Retail segment leads total volume (₹ 0.77M), followed by Premium (₹ 0.22M) and SME (₹ 0.16M).
- **Top Transaction Categories:** Loan EMIs (₹ 0.48M) and Direct Transfers (₹ 0.35M)[cite: 1].
- **Geographic Performers:** Gujarat (₹ 0.21M), Karnataka (₹ 0.17M), and Maharashtra (₹ 0.16M)[cite: 1].
- **Transaction Health:** 87.9% Success, 10.2% Failed, and 1.9% Pending[cite: 1].
